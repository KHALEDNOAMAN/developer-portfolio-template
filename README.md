# Developer Portfolio Template

A stunning, premium, responsive, and animated developer portfolio template built with React, TypeScript, and Vite.

## ✨ Features
- **Modern Design:** Premium dark theme with glassmorphism and smooth gradients.
- **Responsive:** Mobile-first design that looks great on all devices.
- **Animated:** Smooth scroll animations using Framer Motion and Intersection Observer.
- **Easy Customization:** Edit a single `src/config/data.ts` file to update all your content.
- **Tech Stack:** React 18, TypeScript, Vite, CSS (no utility classes needed), React Icons.

## 🛠️ How to Fork & Customize
1. **Fork the Repository:** Click the 'Fork' button at the top right of this page.
2. **Clone your Fork:** `git clone https://github.com/YOUR-USERNAME/developer-portfolio-template.git`
3. **Install Dependencies:** `npm install`
4. **Run Locally:** `npm run dev`
5. **Customize Data:** Open `src/config/data.ts` and fill in your personal information.
6. **Customize Assets:** Replace the placeholder images in the `public` or `src/assets` folder.
7. **Deploy:** Push your changes and deploy to Vercel, Netlify, or GitHub Pages.

See [CUSTOMIZATION.md](CUSTOMIZATION.md) for more details.
